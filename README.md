# 任务路由 · DSH 单会话入口

在 DSH 左侧栏打开「任务路由」，用一段话描述工作。**一次提交只选一个执行会话，整段原文一起发送。** 路由可以跨你已授权的项目查找目的地，但不会把列表、分号或「先……然后……」拆成多条投递。某个项目的所有工作也不会因此都挤进同一个会话。

## 怎么用

1. **提交**：直接说要做什么，不必先选工作区或会话。默认自动续接同一件事；独立的新工作自动选一个获准目录新建。只有确实需要你决定的情况才停在「待选择」，例如同时点名两个项目，或要求接着做却找不到所指的会话。
2. **看记录**：每次会话请求是一条紧凑记录。直接看状态、任务摘要以及「新建 / 续接 · 工作区」；展开再看路由依据、完整文本、结果或处理待选择项。追问留在原会话，不再经过路由器选目的地。
3. **看原会话**：从记录打开页内侧栏，左边任务台仍保留。安装版嵌入 DSH 的原生对话视图，可看实时进展，并按原会话的权限交互；收起侧栏不会停止任务，也不会跳转主页面。历史会话若尚未载入，要再点「载入原会话」才会唤醒；仅预览候选不会唤醒它。
4. **清理**：单条可手动移除，也可确认后批量清理已完成记录。只移除当前浏览器的路由记录和它提供的匹配线索，不删除、归档或取消 DSH 会话。单条入口在「展开详情 → 删除记录」；「清理已完成」只清理按下时列出的已完成记录，确认期间新完成的不会被追加进去。正在派发、执行中、等待回执或仍需恢复的记录受保护。

[试用离线演练](examples/try-router.html)：可依次试「不点项目」「接着刚才」，查看同一会话的两份回执；也可试「多步只进一个会话」或「目标冲突」。使用同一界面、规划器和状态机，但所有任务、侧栏对话和回复都是虚构数据，不联网、不运行模型。打开 HTML 即可，刷新重置。

## 安装到实际 DSH

适配版本：**DSH 0.2.2-rc.5**（包括这个版本的桌面端）。宿主接口目前不是跨版本兼容层。版本不符时请勿强制豁免安装。

1. 在**你已登录的 DSH** 侧边栏进入 **插件 → 添加/安装插件**（选本地包），填入你克隆本项目的**绝对目录**（在项目根目录运行 `pwd` 即可取得）。

   也可以安装本地构建好的压缩包：同一安装框填入压缩包的**绝对路径**。安装的是当前 profile 的宿主和客户端插件，会向该 profile 生效；本项目的演练和测试不会自行做这步。不要用不同版本的全局 `dsh` 命令修改正在运行的桌面 profile。
2. 确认并启用 `dsh-router-agent`。按插件管理器提示刷新；**只有提示需要重启时**，先保存当前工作再重启 DSH。找不到「任务路由」时，可在插件列表查看该包和当前页面的启用/加载状态。没有开发 watcher 时，编辑源码不会自动更新安装包。
3. 在「任务路由 → 路由设置」中选择**已有**的通用工作目录，添加允许处理的项目目录和易识别的项目名。允许只配置通用目录。不会扫描子目录来扩大许可范围，也不替你创建项目文件夹。
4. 在「按任务选择模型」选择**自动**，选定一个 DSH 已配置的提供方，预览快速、标准、深度三档的实际模型和思考强度，再保存。也可以选**手动**指定三档。若只提供一个可用型号，同一型号可能按支持的思考强度区分，不会伪造三个模型。新会话的「标准模式 / PTC 模式 / 跟随 DSH 默认」单独设置；这不是模型强度。

卸载或暂停：在同一插件页关闭/移除此包。关闭入口不会撤销 DSH 已接受的任务，也不会删除已有执行会话。

### 从 0.2.1 更新到 0.2.2：意图分类不再被过早中止

如果旧版显示 `Remote invocation "routerAgent/infer" was aborted`，这指的是**投递前选目的地的分类请求**，不是执行会话的失败回执。旧页面会在 6.5 秒主动取消推理；关闭面板或连接重建也可能取消请求，不能据此判断模型离线。先看任务记录：若已排队、运行中或已完成，**不用重发**。

- 默认自动模式下，能在本地定下的明确任务不必等模型。需要模型区分语义时，给宿主完整的 30 秒分类预算，客户端只在另加 5 秒仍无回包时兜底，不二次调用或改换提供方。
- 真实超时、快速档不可用或模型输出无效时，会在**这一条记录的路由详情**说明为什么采用本地规则，不再用一个长期悬挂的模型不可用提示覆盖任务状态。权限丢失、面板在分类时关闭或投递前的目录复核失败时，不会据此发送。
- 升级后刷新路由页即可。无需改模型、重存设置；也不会重放原任务。

### 从 0.2.0 更新到 0.2.1：少手选

- **已有设置不用动。** 之前没有「工作区与会话路由」字段的安装，也默认「自动选择」。它与模型分档、会话预设相互独立。想保留原来的审慎程度，可在路由设置里选「不确定时先问我」。
- **先找事项，再选目录。** 看用户明确指定的目标、已接纳的任务、项目名和实际会话的工作线索。“刚才那版再短一点”这类短追问可以续接路由台刚投递的会话，不拿宿主最近打开的无关会话冒充。单纯同属一个项目不会把新工作并入上次对话。
- **没匹配上旧会话不等于需要确认。** 新工作直接新建；通用写作和问答优先用通用目录，项目任务先按领域线索选，仍无可靠线索才用已设置的默认项目，再兜底到项目列表第一项。可以设一次默认项目来指定这个退路，不是每次必填。
- **不会扩大授权或补发旧任务。** 指令冲突、明确点名的目录不在范围、要跟进但原会话无法确认时，仍会停住。对升级前已经显示「待选择」的记录，可主动重新匹配；不会在后台替你重发。

### 从 0.1.x 升级到 0.2.0

不用清空站点数据。已有目录、选模设置、未完成任务的请求号及会话绑定原样保留；**新提交**才执行单目标约束。旧版已保存的多项任务仍可展开核对和完成原有的交接、恢复或追问，不迁移、不重发。升级后刷新已打开的路由页一次。

### 0.1.x 历史更新：0.1.4 / 0.1.5

- **带链接的投递类任务。** 「帮我投递 <链接>」「帮我申请/报名/填写…」现在会被当作可执行工作：只在一个项目做过同类工作时直接落到该项目，不再要求先说明要做什么。链接是独立的投递对象：**同一个链接**再次提交会续接原会话，**不同链接**照常在该项目新建，不会混进上一份投递。
- 已有状态为「待选择」的分项，刷新页面后点 **「重新匹配此项（不发送）」** 即可按新规则重算，确认后才会发送。

### 从 0.1.2 更新到 0.1.3

- **免重复选项目。** 唯一获准的工作项目、明确的项目标记或唯一同一事项的会话可以直接确定目录。通用写作/问答走通用目录。多个项目时，可在设置里一次性选择「未指名项目时的默认项目」用于没有其他线索的独立工作；不会盖过明确提到的项目，也不会替你在多个相似会话中猜一个。
- **按实际工作选执行模型。** 轻量修订、常规实现、系统性分析分别按快速、标准、深度处理；可显式要求档位。旧版三档完全相同（含思考强度）时默认转用自动策略，只在已选提供方的真实目录内映射。之前已配成不同档位的保留手选；也可显式手动固定三档相同。结果卡区分创建计划与宿主确认的模型。复用时不更换模型。
- **更新前已经在等你选项目的独立分项**可以点「重新匹配此项（不发送）」。核对推荐后再点「使用此会话」或「在此新建」。这不会重提整条请求；已执行的任务不会因此重发或合并。
- **不必说“继续”。** 入口用本地已接纳分项的原始任务和实时会话目录作为匹配线索，不依赖会话标题已更新。即便原会话正忙，只要能证明同一项工作、同一目录也可排队。主题相近但目标、对象、日期或工单冲突时，不因“上次刚用”而复用；明确要求另开会话也不会被忽略。
- **新建模式独立。** 旧版未传 `agentPreset`，继承了 DSH 当前选中的预设；若当前选的是 PTC，新开也为 PTC。0.1.3 路由新建默认明确用**标准模式**，可在设置里选 **PTC 模式** 或 **跟随 DSH 默认**。不改 DSH 全局预设和已有会话，也不会把升级前已发出的创建键改成不同预设。

### 从 0.1.1 更新到 0.1.2

如果旧分项显示 **The router could not confirm a newly created persistent session**，不要重发整单。DSH 桌面可在新会话写入三条权限设置和一条子代理选模策略；这四条都是初始化，不代表开始执行。0.1.2 识别这组记录；任何工作消息、排队记录、未知事件或重复策略仍不能算空白。

刷新 DSH 页面，打开原失败分项的 **预览空会话恢复**。核对目标目录及会话 ID 后点 **确认恢复并仅投递此项**。入口只核验这个持久空会话并沿用其当前模型，不另建、不更改模型，不自动恢复其他失败项。已归档、有工作记录或身份不符时会停止。如果宿主明确证明会话不存在，可按界面提示以同一创建键重试；不需要清除浏览器记录。如果同一需求曾被手动提交多次，**只确认你要执行的那一项**。

### 从 0.1.0 更新到 0.1.1

0.1.1 修复了新建会话时出现的 `cannot get property "remote.routerAgent" without inject`。更新后刷新 DSH 页面，再打开「任务路由」。在原来的失败分项点 **重试此项**，不必重新发送整条任务。版本更新不会重置已有的目录、模型设置或任务日志；已投递的其他分项不会因重试本项而重发。

## 预期行为

| 你发的内容 / 情况 | 实际行为 |
| --- | --- |
| 「在 A 先检查发布说明，再列出验收清单。」 | 只匹配 A 的一个会话，保留两步原文，发出一个请求。 |
| 「给 A 项目改接口，同时给 B 项目更新文档。」 | 不拆，整条停在待选择。选定一个目标后才向那一个会话投递。 |
| 「刚才那版再短一点。」 | 当前路由台有一个可核实的最近接收会话，就续接原会话；不是挑整个 DSH 最近打开的一条。 |
| 相关会话不止一个，但没有证据表明这是同一件事 | 独立的新请求自动选工作区新建；若明确要继续某项工作却分不清，可就地查看候选。 |
| 「用深度档，在 B 项目另开会话排查性能瓶颈。」 | 按指定档位新建。其他新任务按复杂度选档；续接不换模型，不改 DSH 全局默认。 |
| 已绑定的会话正忙，或你想接着问 | 新消息交给同一会话；原生队列处理忙碌状态，入口不另开一个。 |

## 安全边界与持久性

- **只服务本人的 DSH 会话。** 客户端使用当前已鉴权的 DSH Remote；宿主的创建、局部选模和轻量分类端点均检查真实 owner 身份。没有外部服务，没有单独监听端口，不修改应用安装目录。仍沿用执行会话自己的权限和审批规则，入口不代批。
- **先元数据后摘录。** 候选只包括许可的精确目录、未归档的普通可续聊会话。排除子代理、未使用的空会话、需要迁移或无法证实目录的会话；原生列表仍标空白但能精确核实已投递请求的会话可以续接；工作目录发生漂移不会跟着投递。仅在需要时获取少数候选的近期用户文本。路由分类使用快速档、禁用工具，有输入/输出预算；只给分类器本次任务、少量候选标题和必要的短摘录；需要辨认项目语义时，最多提供四个获准项目的短标签或当前请求中的匹配词，使用临时编号而不是目录路径，不附整段历史。本地已投递任务的原句只在当前入口匹配，不直接转给分类器。所选模型提供方依然会收到参与分类的这些文本。分类器不可用或输出无效时仍按本地策略自动路由，不会单因为模型说“不确定”就弹出选择；可在详情查看依据。
- **状态不靠猜。** 每项用固定的创建键、投递请求号和投前游标。只有在连续事件中能把该输入、对应轮次、最终文本和成功结束关联起来才显示「已完成」。成功入队不是执行成功；超出核对窗口、同轮混入其他人工输入或无可归属文本时显示「状态未知」。这时优先查看原会话或刷新，不要当成失败重复新建。
- **任务记录只在当前浏览器和这个 DSH 站点保存。** 本地日志使用 Web Locks，跨标签页的提交、重试和清理均串行处理，不跨设备同步。日志可能含敏感内容，浏览器存储不是加密保险箱。用界面清理，不要清空整个站点。关闭页面不影响已入队的 DSH 工作；下次打开时入口会核对状态。
- **侧栏不会增加会话权限。** 当前所有者、已授权目录与实时原生会话资格均须有效，不能通过历史记录查看已撤权或已归档的对话。没有使用新窗口、替换整个 DSH 页面或改写宿主安装目录来模拟嵌入。

## 开发与验证

Node 22+；运行时使用宿主提供的 DSH 库，唯一的构建依赖是 esbuild。仓库内带有可加载的客户端产物和单文件演练。

```sh
npm ci
npm run check                 # 重建客户端/演练，随后运行 Node 自动测试
node scripts/verify-package.mjs  # macOS：用真实桌面 CLI 在临时 DSH_HOME 组合 Web 配置，未启动 Web 服务
sh scripts/dsh-runtime-smoke/run.sh  # macOS：在禁网沙箱运行真实 Cordis/Typert、会话引擎、JSONL + 合成模型
sh scripts/dsh-runtime-smoke/run.sh --ledger-only  # 只验一条原文、一份回执、原会话侧栏和清理
sh scripts/dsh-runtime-smoke/run.sh --automatic-only  # 多工作区、无手工选择：选目录、新建、续接和拒绝越界
sh scripts/dsh-runtime-smoke/run.sh --slow-infer-only  # 故意让分类用 7.3 秒，验证进正确工作区且只执行一次
npm pack                      # 打出可安装的 .tgz
```

其他安装位置可把匹配版本的 DSH CLI 绝对路径传给配置验证脚本。测试仅在隔离环境内使用虚构的任务或合成模型，不借用正常用户的会话作为测试目标。[真实宿主烟测及覆盖边界](scripts/dsh-runtime-smoke/README.md)包含仅 owner 可用、忙时排队、重复请求无第二轮、错误请求号不取旧结果、会话选模不改全局、归档后拒投等检查。

### 代码入口

- [DSH 模块与侧栏面板](src/client.mjs)：官方模块工厂、owner 门禁、挂载及刷新回收。
- [宿主半侧](src/host/index.mjs)／[共享 RPC 合同](src/host/contract.mjs)：无工具推理、安全新建和仅本会话的选模。
- [单目标路由](src/planner/index.mjs)：在允许目录内按证据选择一个目的地，不对原文分段执行。
- [状态机](src/core/controller.mjs)／[日志](src/core/journal.mjs)：单请求幂等投递、安全清理，以及旧版记录恢复。
- [DSH 适配器](src/dsh/adapter.mjs)／[结果归属](src/dsh/observation.mjs)：宿主协议、许可边界与按请求核对轮次。
- [任务台](src/ui/main.mjs)：紧凑记录、详情、手动清理与原会话侧栏。
